
# AI Infographic Set on Social Topics

## Project Description
This Python project generates social awareness infographic images.

## Topics Covered
- Environmental Awareness
- Cyber Safety
- Education for All

## Technologies Used
- Python
- Matplotlib

## Features
- Generates three infographic designs.
- Displays awareness points and action messages.
- Saves infographic images in PNG format.

## How to Run
1. Open Google Colab.
2. Copy the code from ai_infographic.py.
3. Run the code to generate the images.

## Output Images
- environment_infographic.png
- cyber_safety_infographic.png
- education_infographic.png

## Conclusion
This project promotes social awareness through infographic designs.
